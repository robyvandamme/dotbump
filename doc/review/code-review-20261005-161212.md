## Summary

The repeated `--exclude` option is carried through settings, the command, handler, and package-file scanner, with tests covering forwarding and directory pruning. ## Medium severity

### M1. Exclusion matching is case-insensitive on every filesystem

**File:** `src/DotBump/Commands/BumpPackages/PackageFileService.cs:326, 334-337`

Both the normalized exclusion set and the path comparisons use `StringComparer.OrdinalIgnoreCase` / `StringComparison.OrdinalIgnoreCase`. On case-sensitive filesystems, such as the usual Linux configuration, directory names differing only by case are distinct paths.

For example, if a repository has both `Packages/` and `packages/` and the user excludes only `packages/`, `IsExcludedDirectory` also matches and prunes `Packages/`. Package references in the latter directory are then absent from the manifest and are not bumped, despite that directory not being selected for exclusion.

Use path comparison semantics appropriate to the filesystem/platform, and add a test that creates two differently cased sibling directories on a case-sensitive filesystem and verifies excluding one leaves the other included.
